# Protocol

Current wire format is unicast RTP over UDP carrying L16 audio.

- RTP version: 2
- Payload type: 96 (dynamic)
- Codec: L16
- Sample rate: 48000 Hz
- Channels: 2
- Sample size: 16-bit
- Byte order in RTP payload: big endian
- Default packetization: 5 ms / 240 audio frames
- Default payload size: 960 bytes
- Default RTP packet size: 972 bytes

SDP description:

```text
m=audio 5004 RTP/AVP 96
a=rtpmap:96 L16/48000/2
a=ptime:5
```

Sequence numbers increment by one per packet. RTP timestamps increment by the number of audio frames in the packet. SSRC is generated by the sender and remains stable for the sender lifetime.

The receiver validates RTP version, payload type and optionally SSRC. It tracks duplicates, late packets, reordering, packet loss and interarrival jitter.
